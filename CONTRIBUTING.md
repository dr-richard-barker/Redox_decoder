# Contributing to Arabidopsis ROS Decoder

We welcome contributions to the **Arabidopsis ROS Decoder** repository! Whether you are reporting bugs, requesting features, submitting code improvements, or contributing new spaceflight dataset validations, your input is appreciated.

## How to Contribute

1. **Fork the Repository**: Create your own fork of `dr-richard-barker/Redox_decoder`.
2. **Create a Feature Branch**: `git checkout -b feature/new-validation`.
3. **Commit Your Changes**: Follow clear commit messages (`git commit -m 'Add validation for OSD-XXX'`).
4. **Push to GitHub**: `git push origin feature/new-validation`.
5. **Open a Pull Request**: Submit a PR describing your proposed changes and evaluation metrics.

## Code of Conduct

Please maintain an inclusive, respectful, and open scientific collaboration environment.
